Feature Descriptions

Reference guide for spoofing and protection features

  • Spoof User Agent: Turn off to keep your real User-Agent while running individual features below.
  • Touch Spoofing: Spoofs touchscreen capability (0 = desktop, 5 = phone, 10 = tablet).
  • Block JavaScript: Blocks all JS execution. Reload pages after toggling.
  • Detection Shield: Spoofs navigator, plugins, canvas & WebGL fingerprints to prevent detection.
  • Location Spoofing: Overrides the Geolocation API with preset or custom coordinates.
