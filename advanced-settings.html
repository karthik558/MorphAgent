How to Use MorphAgent Protections

MorphAgent is modular. You can toggle specific protections from the main extension popup depending on your privacy needs:

  • For basic website compatibility: Simply select a device profile and enable User Agent Spoofing.
  • For maximum anti-tracking: Enable the Detection Shield to spoof your hardware fingerprints (Canvas, WebGL, Fonts, Audio).
  • For advanced evasion & testing: Turn on Ghost Mode to auto-rotate your identity, and enable the WebRTC Shield to hide your real IP.
Spoof User Agent & Client Hints: Automatically modifies HTTP Headers (Sec-CH-UA) and navigator.userAgentData to match the selected device.
Touch Spoofing: Modifies navigator.maxTouchPoints to accurately emulate touchscreen capability (0 = desktop, 5 = phone, 10 = tablet).
Detection Shield (Canvas & WebGL): Spoofs UNMASKED_VENDOR_WEBGL and UNMASKED_RENDERER_WEBGL, and injects cryptographic sub-pixel noise into toDataURL() and getImageData().
Ghost Mode (Auto-Rotation): Automatically rotates your entire browser identity (User Agent, Touch Points, Canvas Seed) at configurable intervals to break persistent tracking sessions.
ClientRects & DOM Bounding Box: Intercepts getBoundingClientRect to inject microscopic noise, destroying OS-level font rendering and layout tracking vectors.
WebRTC IP Leak Shield & Network: Silently strips local IPs from WebRTC offers and spoofs navigator.connection to perfectly match your selected device profile (e.g. 4G cellular).
Battery API & Sensor Spoofing: Spoofs navigator.getBattery() to return a fake, slowly discharging 85% battery level across all tabs.
Font Enumeration Defender: Defeats font hashing by adding variance to offsetWidth/offsetHeight, and masks behavioral biometrics (mouse jitter/typing).
AudioContext Fingerprint Shield: Introduces imperceptible frequency noise into AnalyserNode.getFloatFrequencyData and offline audio buffers.
GPS Geolocation & Timezone: Overrides the Geolocation API (getCurrentPosition) with preset coordinates, and applies synchronous Intl.DateTimeFormat timezone spoofing.
Screen & Media Devices Masking: Spoofs screen.width/height, pixel depth, orientation, and deterministic webcam/microphone enumeration masking.
Block JavaScript (Optional): Drastically blocks all inline and external JS execution via injected Content-Security-Policy rules. Reload required after toggling.
